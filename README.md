# ShiftWheel

Конвертер файлов для Windows в духе Tangerine для Mac: берёшь файл в Проводнике или на рабочем столе, начинаешь тащить, нажимаешь **Shift**. Вокруг курсора появляется колесо. Бросаешь файл на сектор, и рядом с оригиналом появляется результат.

## Запуск

1. Запусти `dist\ShiftWheel.exe`. В трее появится оранжевая иконка (нужен .NET 10 Desktop Runtime, у тебя он уже есть).
2. Для картинок, видео и аудио нужен **ffmpeg**. Если его нет: `winget install Gyan.FFmpeg`.
3. Правый клик по иконке в трее → **«Запускать вместе с Windows»**, чтобы стартовало само.

## Что умеет

| Тип файла | Внешнее кольцо (форматы) | Внутреннее кольцо (инструменты) |
|---|---|---|
| Картинки (png, jpg, webp, bmp, gif, tiff, ico, avif) | PNG, JPG, WEBP, PDF, TXT (OCR), DOCX (OCR), GIF, ICO, BMP, TIFF | Сжать, без метаданных, размер 50%, повернуть |
| Видео (mp4, mkv, mov, avi, webm…) | MP4, MKV, WEBM, MOV, AVI, GIF, MP3, WAV, M4A | Сжать, без метаданных, размер 50%, повернуть |
| Аудио (mp3, wav, flac, ogg, m4a…) | MP3, WAV, FLAC, OGG, M4A, AAC, OPUS | Сжать, без метаданных |
| PDF | PNG, JPG, WEBP, BMP, TXT (OCR), DOCX (OCR) | нет |
| Word (doc, docx, rtf, odt) | PDF, DOCX, TXT | нет |
| PowerPoint (ppt, pptx, odp) | PDF, PNG и JPG (по файлу на каждый слайд) | нет |
| Excel (xls, xlsx, ods) | PDF, XLSX, CSV (первый лист) | нет |

* Можно тащить сразу несколько файлов одного типа.
* Результат сохраняется рядом с исходником. Оригинал не трогается, при совпадении имени добавляется `(1)`.
* Внизу справа появляется карточка прогресса. Клик по ней открывает папку с результатом.
* Если отпустить файл **мимо колеса**, сработает обычное Shift+перетаскивание Проводника (перемещение).
* **Esc** во время перетаскивания отменяет всё.

## Ограничения

* OCR (TXT/DOCX) использует распознавание текста Windows и языки из твоего профиля (Параметры → Язык и регион). DOCX получается с простым текстом без вёрстки.
* PDF защищённые паролем не открываются.
* Word, PowerPoint и Excel конвертируются через установленный у тебя Microsoft Office, поэтому он должен быть на компьютере. Если Word/PowerPoint/Excel уже открыты, они не закрываются.
* Колесо работает только для файлов в Проводнике и на рабочем столе.

## Командная строка и отладка

```
ShiftWheel.exe --convert <файл> fmt:PNG
ShiftWheel.exe --convert <файл> tool:compress     (strip | resize | rotate)
```

Лог работы колеса: задай переменную `SHIFTWHEEL_DEBUG=1` перед запуском, лог будет в `%TEMP%\shiftwheel.log`.

## Сборка из исходников

```
cd ShiftWheel
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```
